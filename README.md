# LGA Shot Player — Releases

Este repositorio no tiene codigo: existe solo para publicar los artefactos del
**LGA Shot Player** y para que el auto-update de la app pueda leerlos sin credenciales.

## Descargas

Ir a **[Releases](../../releases/latest)** y bajar segun la plataforma:

| Archivo | Para que sirve |
|---|---|
| `LGA_Shot_Player_Mac_v<version>.dmg` | Primera instalacion en macOS (arrastrar a Applications) |
| `LGA_Shot_Player_Setup_v<version>.exe` | Primera instalacion en Windows |
| `LGA_Shot_Player_Mac_v<version>.zip` | Actualizacion in-place de macOS; lo usa el auto-update, no hace falta bajarlo a mano |

## Actualizaciones

La app chequea sola si hay una version nueva al arrancar y avisa cuando la hay.
Se puede apagar, o forzar el chequeo, en **Preferences > General**.
